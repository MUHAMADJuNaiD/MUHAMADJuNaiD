# Outlook Styles – Demo v2: "Colour Story" theme

15 demo posters, 4:5 (1080 × 1350), one for each product category. Nothing goes into bulk production until Junaid approves.

- `posters/` – final PNGs, ready for Instagram
- `instagram-grid-preview.jpg` – how the profile grid looks with the 3:4 crop
- `all-posters-overview.jpg` – all 15 posters on one sheet
- `source/` – template generator, poster configs, fonts, product cut-outs

## Theme: Colour Story (Tonal Colour-Block, Option A)

Every poster uses the same master system:

| Fixed element | Spec |
| --- | --- |
| Masthead | "OUTLOOK STYLES", Montserrat SemiBold, wide tracking. Left: "COLOUR STORY". Right: category name |
| Background | Solid rich colour with a centre glow and edge vignette, plus film grain |
| Big word | Playfair Display Black in a tonal shade of the background, sitting behind the product |
| Headline | Playfair Display Italic 74 px, bottom left, with a gold kicker line above it |
| **Colour chip** (signature element) | Paint-swatch card in the product's colour with its colour name (Cherry Red, Cocoa Brown, …). No numbers |
| CTA bar | "DM TO ORDER →" on the left · "DELIVERY ALL OVER PAKISTAN" on the right |
| Frame + sparkles | Thin inset frame and 2–3 small gold four-point stars |
| Removed | Prices, N° numbering, the "OS" stamp |

## Layout style for each category

| Category | Style | What makes it different |
| --- | --- | --- |
| Handbags | **Spotlight Arch** | Tone-on-tone arch with gold outline, big word above |
| Tops, sweatshirts, winterwear, blouses | **Stacked Type** | Big word repeated 3× (solid, outline, outline) behind the garment |
| Bottoms and long dresses | **Vertical Type** | Huge vertical word on the left, tall product on the right, small vertical tag |
| Eid / Eastern | **Jharoka Arch** | Mughal cusped arch with a double outline in cream, festive saffron colour |
| Sunglasses (single) | **Sun Disc** | Big circle "sun" behind the frames plus a floor reflection |
| Sunglasses / any 3 products | **Trio Edit** | 3 products zig-zagged, each with a name label (no numbers) |
| Flats and jewellery | **Details** | Medallion spotlight plus callout lines naming features |
| Brand | **Manifesto** | Typography only, with a product strip |

## How to rebuild (for bulk)

```bash
python3 source/gen.py <build_dir> <cutouts_dir>      # posters.json -> html/
node source/render.js <build_dir>/html <out_dir>     # html -> PNG (Playwright)
```

`gen.py` reads `posters.json` from `<build_dir>` and `fonts/fonts.css` from `<build_dir>/fonts/`. Each new poster is one JSON entry: variant, palette, image, word, box, copy and chip.
