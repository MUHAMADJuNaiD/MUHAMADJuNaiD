OUTLOOK STYLES REEL KIT - SHURU KAREIN (bina credits ke)
=======================================================

EK DAFA SETUP (sirf pehli baar):
  Windows:  "1-SETUP-WINDOWS.bat" pe double-click karein.
            Agar wo kahe "dobara chalayein" to window band kar ke phir double-click karein.
  Mac:      "1-SETUP-MAC.command" pe double-click karein
            (agar Mac roke: right-click > Open > Open).
  Internet chahiye. 10-20 minute lag sakte hain.

REELS BANANA (har baar):
  1) "reels.json" ko Notepad mein kholein. Har reel ki ek line:
        { "product": "0" },
        { "product": "212" },
        { "product": "36" }
     (aakhri line ke baad comma NAHI lagana. Brackets [ ] ke andar rakhein.)
     Product number kahan se milega? posters/bulk folder mein poster ki file ka shuru wala number
     (jaise "036-campus.jpg" = product 36), ya data/products.json mein "id".
  2) Windows: "2-MAKE-REELS-WINDOWS.bat" double-click
     Mac:     "2-MAKE-REELS-MAC.command" double-click
  3) Reels "out" folder mein aa jayengi (MP4 + cover JPG). 2K, 30 fps, Instagram-ready.
     Instagram pe trending audio khud lagayein.

TEZ MODE: agar computer mein graphics card hai to "2-MAKE-REELS-FAST-GPU-WINDOWS.bat" try karein.

MASLA AAYE TO: "out" folder khaali ho ya error aaye, to window ka screenshot le kar bhej dein.
NOTE: Abhi template v1 hai. Naya v2 template (nayi session bana rahi hai) approve hone ke baad
      sirf hero2.html aur hero2.js files is folder mein daalni hongi, aur reels.json mein "template": "hero2".
