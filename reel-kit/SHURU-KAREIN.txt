OUTLOOK STYLES REEL KIT v2 - SHURU KAREIN (bina credits ke)
=========================================================
Is folder mein: 160 HD products + data + template v1 (hero) aur v2 (hero2)
+ MUSIC aur SOUND EFFECTS (audio folder) - sab automatic lagte hain.

EK DAFA SETUP (agar pehle kar chuke hain to dobara zaroorat nahi,
sirf naya folder hai to "1-SETUP" phir chalayein):
  Windows: "1-SETUP-WINDOWS.bat" double-click (agar kahe dobara chalayein, to dobara).
  Mac:     "1-SETUP-MAC.command" double-click.

REELS BANANA:
  1) "reels.json" Notepad mein kholein. Har reel ki ek line, misaal:
     [
       { "product": "0",   "template": "hero2" },
       { "product": "212", "template": "hero2" },
       { "product": "36",  "template": "hero2", "music": "02-luxe-night-120bpm.mp3" }
     ]
     - Aakhri line ke baad comma NAHI.
     - Product number = poster file ka shuru wala number (posters/bulk/...  036-campus.jpg = 36),
       ya data/products.json mein "id".
  2) Windows: "2-MAKE-REELS-WINDOWS.bat"   |   Mac: "2-MAKE-REELS-MAC.command"
  3) "out" folder mein har reel ki 3 files:
       naam.mp4            -> music + sound effects ke saath (seedha post karein)
       naam-sfx-only.mp4   -> sirf sound effects (Instagram pe trending gaana khud lagane ke liye)
       naam-cover.jpg      -> cover / thumbnail

MUSIC:
  - "music" na likhein to khud choose hota hai (product ke rang/category ke hisaab se).
  - Apna music: royalty-free MP3 "audio/music" folder mein daalein aur naam "music" mein likhein.
    (Pixabay Music / YouTube Audio Library - 120 BPM tracks best. Bollywood gaane NAHI.)
  - Music bilkul nahi chahiye: "music": false   |   koi sound nahi: "sound": false

OPTIONAL: "hookLine": "WINTER, BUT MAKE IT SHINE."   (hook ke neeche chhoti line)
          "calls": [...]  feature callouts (reels.json ki gloss puffer misaal dekhein)

TIME: ek reel ~8-10 min (graphics card ho to "2-MAKE-REELS-FAST-GPU-WINDOWS.bat" se tez).
      20-30 reels ek saath likh kar raat ko chala dein.
MASLA: error aaye to window ka screenshot bhej dein.
